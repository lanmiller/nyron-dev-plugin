# Массовый продукт из подхода STOVP — ресёрч рынка

Дата: 25.08.2026. Статус: ЗАВЕРШЁН — 2 раунда параллельных веб-агентов
(4 + 3 трека) + ручная проверка браузером; третий заход принёс одну
находку (Ventora живьём) — дальнейшие ниточки упираются в недоступные
отсюда источники (живой Reddit, письмо в VK). Полные отчёты треков — в
транскриптах сессии; здесь — синтез.

## Гипотеза продукта

Вертикальная автономная фабрика: **идея → ресёрч → продуктовая гипотеза →
дизайн → прототип → посадочная → рекламные кампании → замер → вердикт
«гипотеза жива/мертва»**. Основа — наработанное: методология плагина
nyron-dev (гриль → гипотеза → эпик → волны → QA → замер), фабрика
оркестрации CLI-сессий (пульт/STOVP), симбиоз семей моделей, коннекторы
(SEO, соцсети, рекламные кабинеты). Позиционирование: НЕ универсальный
агент-бот, а вертикаль «создание продукта». UX-финал: «всё собрано и
настроено, вот смета — жми запуск». Дальше лестница: Проверка → Рост
(SEO/соцсети/доработка) → Сопровождение.

## Вердикт ресёрча (вывод первым)

1. **Ниша реальна и пуста в серьёзном сегменте.** Спрос доказан деньгами
   (Lovable ~$500M ARR, Replit $525M — но все монетизируют только сборку);
   боль «собрал — а пользователей нет» массовая; полный цикл с рекламой и
   вердиктом не закрывает никто работающим продуктом. Заявки есть только
   на игрушечном конце (Ventora $99, CoFounder.AI $39/мес — сырой).
2. **Продаём результат, не доступ к фабрике.** Сошлось с трёх сторон:
   юридически (пул подписок для чужих нагрузок = забаненный паттерн у всех
   вендоров), по рынку (усталость от кредитных моделей, тренд outcome-based),
   по цене (дыра между $25–50/мес self-serve и $15–20k+ агентств).
3. **Экономика сходится.** Себестоимость цикла без рекламы $66–775 (LLM
   $50–500 — покрывается стартап-кредитами; креативы/хостинг ≈ 0), чек
   $500–2000, рекламный бюджет — отдельная явная статья клиента.
4. **Окно ~6–12 месяцев.** Главная угроза — Lovable, ползущий вверх по
   циклу (наём Performance Marketer «строить агентов, которые двигают
   бюджеты»; General Tasks генерит маркетинг-ассеты). Рекламные агенты
   вниз к продукту не идут.
5. **Дефицитный слой — методология, не сборка.** Публичный эксперимент:
   автономный агент (лендинг+аутрич+контент, месяц) = $0. «Агенты
   обрушивают стоимость исполнения, но не стоимость правоты». Сборка —
   commodity; ресёрч → гипотеза → замер → вердикт — то, чего нет ни у кого
   и что у нас уже год работает в бою.

## Раунд 1

### Трек 1. Спрос и цены

- Рынок vibe-coding ~$4,7 млрд (2026), CAGR ~38%; 63% пользователей —
  нетехнические; 80% — соло-билдеры. ARR: Lovable $500M, Replit $525M
  (+1775% г/г), Bolt $40M за 5 мес (цифры вторичные — порядок величины).
- Ценовая лестница: self-serve $25–50/мес ←(дыра)→ done-for-you от
  $15–20k/проект (MVP-агентства $30–150k; лендинг $1,5–3k; настройка
  рекламы $1,5–5k + ведение $500–3000/мес).
- Монетизация: системные жалобы на кредитные модели (годовая подписка
  Cursor сожжена за день); Gartner — 40% enterprise SaaS к 2026 с
  outcome-элементами; «плата за вердикт гипотезы» — незанятая ниша.
- РФ: Lork.dev, GoMVP (499₽/мес; 78% первых промптов — «собери
  сайт/продукт»); Директ под ключ 25–60 тыс.₽; бандл «продукт + реклама»
  не продаёт никто; тестовый бюджет VK Ads 10–50 тыс.₽.

### Трек 2. Автономная реклама — риск снят

- Все 4 площадки (Google, Meta, Яндекс, VK) позволяют стороннему сервису
  вести кампании клиента по официальному API (прецеденты: К50, Elama,
  Marilyn работают так годами).
- Легальная схема = наш UX: разовый OAuth/System User/агентский доступ →
  кампания в статусе черновик/пауза + смета по forecast-API площадки →
  клик клиента «запустить» = API-активация → guardrails (спенд-кэпы,
  лимит частоты правок — у Meta ~4 изменения бюджета/час, журнал).
- Банится: RPA поверх интерфейса, машинная скорость правок,
  «circumventing systems» (38% банов Google). Кейс: полный write-доступ
  ИИ-инструменту → Meta снесла Business Portfolio клиента за неделю.
- Ограничения: модерация после запуска (часы — показывать в UX); Яндекс —
  «паспортные организации» с 28.04.2025; VK — доступ для стороннего SaaS
  только по письму (ads_api@vk.company); аппрувы приложений — недели, разово.

### Трек 3. Подписки и законность — риск подтверждён

- Прямой запрет обслуживать чужих клиентов с подписок у всех: Anthropic
  («may not… resell, or intermediate Claude usage on their end users'
  behalf»), OpenAI, GLM (прямо называет «SaaS products»).
- Энфорсмент: ~1,45 млн банов Anthropic (2П2025), апелляции 3,3%; детект
  паттерна relay/прокси. Мультиаккаунт «для себя» без прокси — терпим.
- Экономика headless-подписок закрыта вендором: с июня 2026 headless
  (`claude -p`, Agent SDK, CI) — отдельный пул Agent SDK credits
  ($20/$100/$200 у Pro/Max5x/Max20x), дальше API-тарифы.
- Легальные пути: API-биллинг; стартап-кредиты; BYO («each end user must
  authenticate with their own credential») — режим для ступени «Рост».

### Трек 4. Конкуренты

- Все крупные билдеры заканчиваются на «код + деплой»; ретеншн
  нетехнических рушится на стыке «прототип готов → а дальше что».
- Частичные закрытия: Lovable General Tasks (генерит ассеты, не запускает),
  Durable (тексты объявлений), Mixo (лендинг-валидация). Связки «рекламный
  агент + билдер» на рынке нет.
- «Вертикаль бьёт универсала» — консенсус: ценность за 6 мес у 71%
  вертикальных против 32% горизонтальных, ROI 2,3×; Operator — 38% успеха.

## Раунд 2

### Конкуренты глубже: окно и фланги

- **CoFounder.AI** — не угроза: рекламу не запускает, Dev Shop = лендинги
  и порталы; отзывы единичные и 1★ («ничего не работает»); скорее личный
  бренд основателя (C. Wooten + книга), данных об инвестициях нет.
- **Ventora (ventora.cc, проверено браузером)** — дословно наша
  формулировка («AI builds the product, runs ads, brings visitors… you
  find out if people will pay»; Google Ads + Stripe + Vercel + Supabase).
  Но: $99 разово за «весь продукт за ~час», free-старт — игрушечный конец
  рынка; за $99 нет ни ресёрча, ни бюджета, ни честного замера. Соцдоказ
  на сайте выглядит сгенерированным. Валидирует спрос на формулировку, не
  занимает сегмент «честный вердикт». Следить.
- **Главная угроза — Lovable:** вакансия Performance Marketer («строить
  агентов в Lovable, которые читают перформанс, двигают бюджеты и вносят
  изменения» — пока для своего маркетинга), General Tasks («целый
  стартап-стек в одном интерфейсе»). Replit Agent 4 дотянулся до
  сторфронтов/платежей. Оценка окна: ~6–12 месяцев.
- Рекламные агенты (AdAmigo, AdStellar, Adsroid, Albert) расширяются вширь
  по площадкам, лендинг требуют на входе — вниз к продукту не идут.
- Контекст: 3800+ агент-стартапов закрылось в 2025, ещё 1800 в начале
  2026 — выигрывает работающий конвейер, не анонс.

### Экономика цикла

| Звено | Min | Max |
|---|---|---|
| LLM-работа (ресёрч+прототип+лендинг) | $50 | $500 |
| Креативы (10–30 картинок + 2–5 видео) | $6 | $55 |
| Хостинг + домен | $10 | $220 |
| **Себестоимость фабрики (без рекламы)** | **≈$66** | **≈$775** |
| Рекламный тестовый бюджет (статья клиента!) | $500 | $2000 |

- LLM-звено покрывается стартап-кредитами (Anthropic $5–100k, OpenAI
  $2.5–50k, Google до $350k, Azure до $150k) — 10–100 циклов бесплатно.
- Рычаг себестоимости: дешёвые модели на рутину (DeepSeek/GLM в 10–20×
  дешевле флагманов) — «симбиоз семей» превращается из фичи в экономику.
- Обязателен потолок трат на цикл (circuit breaker): кейсы «$6000 за ночь»
  у агента без присмотра; Uber $500–2000/инженера/мес.
- Минимум рекламы для сигнала: Meta ~$100/день на вариацию ≈ $1500–3000;
  Яндекс реально 50–100 тыс.₽/мес; технический минимум ниже, но сигнал шумный.

### Боль и каналы (количественно, где удалось)

- Категорийная статистика: лидер вайб-кодинг mobile-приложений — 16k
  скачиваний и $1000 суммарной выручки; №2 — 4k скачиваний, $0. Конверсия
  «построил → продал» ≈ ноль на уровне категории.
- Живые кейсы (Indie Hackers): 3 месяца ежедневных постов → 0 клиентов
  («r/SaaS полон билдеров, а не покупателей»); валидация на 80+ людях →
  $18 MRR («я валидировал идею, а не бизнес»); 1M+ просмотров → $0.
  P. Levels: люди строят «AI-фабрики», но «почти ни у кого нет ни денег,
  ни трафика, и никто не знает, где взять».
- За решение уже платят: VibeUsers $19–39/мес (поиск пользователей под
  готовый vibe-coded продукт), Reddit-агентства $1000–5000/мес, тред
  «фаундеры отдадут 50% выручки тому, кто приведёт пользователей».
  Дешёвые AI-валидаторы ($5–50) — перенасыщенный низ рынка.
- Аудитория (агрегаторы, разброс 2–4×): r/SaaS ~788k (+108% г/г),
  r/vibecoding ~346k (+475% г/г, лидер роста), r/indiehackers ~189k,
  r/nocode ~137k.
- **Канал запуска самой фабрики — не платная реклама:** Lovable и Bolt
  выросли на open source + Product Hunt + личный бренд основателя в X +
  вирусные демо криэйторов. Bolt: один твит → $80k ARR на 2-й день.

## Следствия для дизайна продукта

- Продукт = результат; вход — «цикл проверки гипотезы» фикс-ценой
  ($500–2000; РФ-аналог с Директ/VK), рекламный бюджет — отдельная явная
  статья клиента. Лестница: Проверка → Рост (BYO-ключ клиента легален) →
  Сопровождение.
- Одно окно вместо Jira+пульт+будка: доска гипотез, очередь решений
  клиента, лента работ фабрики (вышка STOVP наружу).
- Себестоимость по API-ценам; модельный микс по ролям; жёсткий бюджетный
  потолок цикла в quality_floor фабрики.
- Реклама — только официальные API, черновик/пауза до клика клиента,
  guardrails; «медленная дисциплинированная фабрика» — фича, не тормоз.
- Отличие от игрушечного конца ($99-сегмента): честный ресёрч ДО сборки и
  честный вердикт ПОСЛЕ замера — то, что нельзя дать за час и $99.

## Открытые вопросы (вне ресёрча — решения и действия)

- Обкатка первой версии: на своих идеях (dogfood: betzo, psylia,
  noproblemo — заодно готовые кейсы для посадочной) или сразу внешний
  клиент? — решение CTO.
- VK Ads API для стороннего SaaS — только прямым письмом (ads_api@vk.company).
- Живой Reddit — недоступен из среды (блок на всех путях, включая браузер
  сессии); количественный подсчёт тредов боли — руками при желании.
- Название/бренд, юрисдикция биллинга, отношение к РФ/глобальному рынку —
  продуктовые решения следующего шага.
