# Ресёрч-дайджест №2 (27.07.2026, вечер)

Четыре прогона: Terra (сверка VISION+SYSTEM-MAP на нестыковки) + Confluence-синк
(веб) + psylia-модель трекера (локальные файлы) + betzo-vault (локально+веб).
Решения по итогам внесены в VISION.md и SYSTEM-MAP.md этим же коммитом.

## 1. Terra: 15 нестыковок — все подтверждены, исправлены

Классы: хвосты ранних решений (nyron-hubd→stovpd, «эпик без клика»,
Parallels/SSH в SYSTEM-MAP); демон описан вотчерами при принятой job-модели;
дорожная карта без честного DAG (этап 4 требовал два аккаунта при вертикали
на одном); UJM-каталог прибит к evolve при универсальной системе; авто-вердикт
гипотез противоречил «вердикты у человека». Исправления — в текущих версиях
VISION/SYSTEM-MAP; главные: демон = jobs/lease/heartbeat (вотчеры только как
гигиена этапа 0), этап 4 разбит на 4а (один профиль) и 4б (мультипрофиль,
failover), DAG: 0 → (1‖2) → 3 → 4а → 4б → 5, вердикт гипотезы = проект от
системы + утверждение человеком (авто — только по заранее заданным порогам).

## 2. Confluence-синк: канон выбран

- **Основной публикатор: md2conf** (hunyadi, PyPI markdown-to-confluence,
  0.6.1 июнь-2026): Cloud API v2, иерархия из структуры каталогов
  (index.md = родитель), жёсткая идемпотентность по `confluence-page-id`
  (инжектится в .md после первой публикации), баннер «generated» из коробки,
  Docker для GitLab CI, mermaid через --render-mermaid.
- **План Б: mark** (kovetskiy, v16.8.1 июль-2026): mermaid без node,
  `--edit-lock` (страницу правит только CI-юзер); минус — шапка-метаданные
  в каждом файле.
- Пайплайн: push в main → CI job (rules: changes: docs/**) → md2conf →
  поддерево «Docs (auto)» под фиксированным parent. Ручные правки витрины
  затираются — поэтому обязательны баннер + label generated + restrictions.
- **Правила**: единственный публикатор — CI (Obsidian в Confluence не пишет
  никогда); страницы людей — вне синкаемого поддерева; MCP confluence_* —
  только точечные ручные операции вне «Docs (auto)».
- Отсеяны: md2cf (мёртвый API v1), confluence.md (без дерева),
  confluence-publisher (AsciiDoc), markdown-confluence CLI (Obsidian-центричен,
  рваный релизный темп).

## 3. Psylia-модель трекера: реконструирована, кандидат в канон

- Лестница та же 6-ступенчатая, но через **ремап в конфиге**: скиллы ходят
  по ключам `backlog/in_progress/review/rework/testing/done`, имена на доске
  любые. **Баг шаблона плагина: в config-template.md только 4 ключа из 6**
  (нет rework/testing) — фикс в этап 0.
- **Два маршрута трекера**: KAN (исполнение: код и контент, один цикл) +
  PROD (продукт: решения людей, ресёрчи, вход Марины; закрывается решением,
  не MR; PROD-тикет = родитель/гейт KAN-тикетов).
- **Слой роадмапа над трекером**: STATUS.md (чекпоинт-журнал, читается первым)
  + ROADMAP.md (потоки «Что | Тикет | Блокер(владелец)» + критический путь).
  Правило: в Jira только приоритизированное; будущее — в роадмапе до
  приоритизации.
- Жемчужины: категория Jira-статуса — часть канона (грабля «Отменено» в
  категории „В работе“ ломало фильтры); tech-debt.md → тикеты грумингом
  пачкой; каждый переход — с комментом.
- Уточнить у постановщика: статусы PROD-доски; нужны ли «Пауза/Дизайн/
  К Выполнению».

## 4. Betzo-vault: модель снята, канон трёх слоёв сформулирован

- Корень betzo = Obsidian vault; код-папки исключены из индексации двойным
  списком (.obsidian/app.json + .smart-env). **У evolve vault уже есть**
  (корень ai-evolve, MOC в ai-evolve-docs-test/_navigation) — канонизация =
  свести две традиции, не заводить новое.
- Практики в канон: пакет-папка на гипотезу (устойчивый id, по нему тикеты и
  Confluence); фронтматтер только у карточек с жизненным циклом; тип заметки
  в имени файла (не теги); канон-файлы с хозяином-ролью и сроком годности
  фактов (90 дней); двухступенчатый поиск агентов (smart-connections →
  obsidian-mcp); журнал «что уточняли — не переоткрывать».
- Связь с Confluence: поле `публикация: <page id>` во фронтматтере;
  переопубликовать = перерендерить из источника.
- Апдейт: dataview дремлет с 2025 — доски по фронтматтеру собирать на
  встроенных **Bases** (Obsidian 1.9+, у evolve включён).
- **Слоган канона: репо — как устроено; vault — что мы думаем и почему;
  Confluence — что мы показываем.**
