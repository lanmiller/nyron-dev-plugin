## Приоритетные проблемы
P2. Композер без программной подписи: #composer-input — только placeholder, aria-label пуст. Читалка не опознаёт главное поле экрана.
P2. Плоская структура для длинной ленты: один H1, 182 таб-стопа, помощь и полные имена — в title. Лендмарки/заголовки секций (транскрипт, вопросы, ход работы) или внутриленточный прыжок.
P2 (известное, заморожено решением CTO). --text-4 = 2.49:1 на bg-2; на нём реальный payload (.tin), 364 повтора в рантайм-скане. Если заморозка снимется — первым снять .tin с text-4.
P3. Десктоп получает телефонные нижние шторки для «посмотреть I/O» при 1500px — на широком уместнее inline/боковая панель.
P3. Сырой payload в человеческой хроме: «работает · <фрагмент брифа>»; нотис «monthly spend limit» — плоский текст с некликабельным URL.

## Мелкие наблюдения
- Свёрнутая пачка честно несёт «⚠ есть ошибка»; фильтр снимается повторным кликом — логично, но без подписи неочевидно.
- Esc не работает при фокусе вне шторки (клик по фону) — платформенный стандарт, но для терминального пульта можно захотеть document-level Esc.
- Диалог «Остановить сессию?» — образцовый: что случится, что цело, как вернуться.
- Фолбэк-пульс на затихших: «затихла · 1 дн» / «затихла · 22 дн» — работает из фактов.
